# PGX 학습 환경

- 하드웨어: NVIDIA GB10 (Blackwell), **aarch64**, 통합메모리 ~119GB, CUDA 13.0 드라이버.
- 컨테이너는 CUDA 13.4를 driver 580 위에서 forward-compat 모드로 실행 (경고 메시지는 정상).
- 호스트에 torch 없음 → aarch64/cu13 휠 호환성 문제를 피하려고 **NGC 컨테이너** `nvcr.io/nvidia/pytorch:26.09-py3` 사용.
- rag-bench용 vLLM 컨테이너 `embed`, `rerank`가 각각 `--gpu-memory-utilization 0.15`로 상주 → 학습 가용 메모리 ≈ 70%.
  필요 시 중지 여부는 소유자에게 먼저 확인.

## 사용법

```bash
scripts/pgx.sh python -m scratchlm.tokenizer data/TinyStoriesV2-GPT4-train.txt data/tok8k.json
```

1. 로컬 레포를 `pgx:~/llm-from-scratch/`로 rsync (`data/`, `runs/`, `.git/` 제외 — 원격에만 존재).
2. 컨테이너에서 `/ws`(=레포)를 cwd로 명령 실행, `PYTHONPATH=/ws`.

데이터: `ssh pgx 'cd llm-from-scratch && bash scripts/get_data.sh'` → `data/TinyStoriesV2-GPT4-{train,valid}.txt`.
